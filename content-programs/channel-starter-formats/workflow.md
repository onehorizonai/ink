# Workflow

## Inputs

- Channel slug from the channel taxonomy.
- Audience and goal.
- Topic or campaign theme.
- Format choice.
- Manual tools involved, if any.

## Steps

1. Select the channel and starter format.
2. Confirm the channel's native reading or viewing behavior.
3. Draft the output with `channel-content-writer`.
4. Add asset, editing, scheduling, or publishing handoff notes when needed.
5. Track the run in `calendar.csv` only when the user wants persisted planning state.
6. Track performance only from real provided metrics.

## Guardrails

- Do not publish, schedule, send, upload, or generate external media unless a real tool is available and explicitly used.
- Do not invent channel metrics.
- Do not treat all social channels like LinkedIn posts.
- Do not create a new platform-specific skill unless repeated use proves the generic writer is not enough.
