# Run Brief Prompt

```text
Create a <format_id> for <channel> aimed at <audience> about <theme>.

Return:
- run_id
- channel
- format_id
- draft or script
- asset requirements
- manual external-tool steps
- review risks
- suggested success metrics

Constraints:
- follow the channel taxonomy
- resolve the channel in the channel/format registry
- load shared channel and format guidance before applying program constraints
- be native to the channel
- do not publish, schedule, send, upload, or generate external media
- do not invent performance metrics
```
