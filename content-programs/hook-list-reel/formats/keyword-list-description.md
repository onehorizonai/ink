# Keyword List Description Format

## Use When

- The Reel needs a long Instagram description that works as a useful list, reinforces the video topic, and helps Instagram understand the content.

## Structure

1. Strong first line that makes the description worth expanding.
2. One short context sentence that names the audience, topic, or problem.
3. Long scannable list of practical items, examples, steps, symptoms, ideas, tools, mistakes, prompts, or checks.
4. Natural keyword coverage across the primary topic, adjacent terms, audience language, and use cases.
5. Short audience-facing bridge that explains why logging, notes, or tracking helps the viewer improve and, when relevant, naturally connects that idea to the selected brand or product.
6. Save, share, or comment prompt only when it is specific and earned.
7. Exactly 5 hashtags at the bottom, supplied by `five-hashtag-set`.

## Check

- The list is genuinely useful enough to save.
- The copy reads naturally and does not repeat keywords mechanically.
- The first line can stand alone in the collapsed caption preview.
- Every item relates to the hook and video.
- Internal production labels such as `<brand> angle:`, `CTA:`, `hook:`, or `note:` do not appear inside the audience-facing description.
- Any brand or product mention reads like part of the caption, not a planning note pasted into the post.
- The description leaves room for exactly 5 hashtags at the bottom.
