# Five Hashtag Set Format

## Use When

- The Reel description needs the required bottom hashtag block for this program.

## Structure

Return exactly 5 hashtags:

1. Niche audience or community.
2. Topic or category.
3. Problem, use case, or intent.
4. Format or content type.
5. Brand, campaign, product, or specific long-tail tag when available.

## Check

- There are exactly 5 hashtags.
- Each hashtag is relevant to the actual Reel.
- The set is specific enough to classify the content for the intended audience.
- No broad vanity, unrelated trend, banned, inactive, or competitor-bait tags are included.
- The hashtags sit at the bottom of the description, not in a separate first comment unless a human explicitly changes the publishing plan.
