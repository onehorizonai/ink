# Workflow

## Inputs

- Event posture: host, attend, sponsor, speak, exhibit, or hybrid.
- Event type: meetup, workshop, webinar, livestream, conference talk, booth, hackathon, roundtable, field event, sponsored event, or custom.
- Audience, goal, timing, location/platform, capacity, budget, partner/sponsor constraints, and owner.
- Target outcome: community, pipeline, partner development, customer education, product feedback, recruiting, content, or thought leadership.

## Steps

1. Choose event posture before drafting assets.
2. Load the event family guide and matching format playbooks from `.agents/channel-content-writer/references/`.
3. Write an event strategy brief with goal, audience, promise, format, budget/risk, and KPIs.
4. For hosted events, write the venue, hospitality, AV, staffing, run-of-show, sponsor, promotion, and follow-up plan.
5. For attended events, write the target list, meeting plan, field notes, booth/speaker obligations, and routing plan.
6. Create the promotion and reminder bundle before registration opens.
7. Create the follow-up bundle before the event happens.
8. Run the event manually and capture notes, questions, photos, recordings, and consent boundaries.
9. Segment follow-up within 24 to 48 hours.
10. Log performance and write a retro with repeat/stop/change decisions.

## Guardrails

- Do not treat event planning as only copywriting.
- Do not claim Ink booked venues, bought food, configured platforms, submitted sponsor reimbursement, scanned badges, updated CRM, or published content unless a real tool did it.
- Do not invent attendance, lead, or pipeline metrics.
- Do not store private attendee lists, sponsor terms, real budget data, or brand-specific assets in this tracked starter pack.
- Do not use sponsor logos, customer logos, photos, recordings, or quotes without permission.

## Output Bundle

Each run should include:

- `brief.md`: strategy, audience, event posture, and success criteria.
- `asset-brief.md`: venue/platform, hospitality, speaker, sponsor, booth, or webinar production notes.
- `outputs.md`: registration copy, promotion assets, reminders, scripts, and follow-up copy.
- `review-notes.md`: sponsor, consent, accessibility, budget, safety, and risk review.
- `handoff.md`: manual logistics, owners, timing, and performance fields.
