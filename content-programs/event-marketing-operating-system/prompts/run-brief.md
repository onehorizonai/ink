# Run Brief Prompt

Use this prompt shape when creating one or more Event Marketing Operating System runs.

```text
Create an Event Marketing Operating System run for <event idea or event name>.

Profile: <selected Ink profile>
Event posture: <host | attend | sponsor | speak | exhibit | hybrid>
Event type: <meetup | workshop | webinar | conference-talk | conference-booth | hackathon | roundtable | field-event | sponsored-event | other>
Audience: <target audience>
Goal: <community | pipeline | partner | customer education | product feedback | recruiting | content | thought leadership>
Timing/location: <date, city, venue/platform, or assumptions>

Return:
- run_id
- recommended channel slug
- event strategy brief
- hosted-event plan or attended-event plan
- promotion and follow-up bundle
- manual logistics handoff
- review risks
- calendar/performance fields to update

Constraints:
- load shared event channel and format guidance first
- separate Ink-drafted assets from manual logistics
- do not invent attendees, costs, sponsors, venues, or performance metrics
- flag sponsor, consent, accessibility, food/beverage, AV, budget, and follow-up risks
- do not publish, book, buy, submit, scan, or update external systems unless explicitly tooled
```
