# Attended Event Plan Format

## Use When

- The team attends, sponsors, speaks at, exhibits at, or networks around an external event.

## Required Output

1. Event selection memo and go/no-go reason.
2. Attendance mode and sponsor/speaker/booth obligations.
3. Target account/person/partner list.
4. Meeting outreach plan and calendar slots.
5. Booth, hallway, or speaker messaging.
6. Field-note and content-capture plan.
7. Lead/conversation tags and routing.
8. Follow-up SLA and message variants.
9. Retro and return/no-return criteria.

## Rules

- Build the target list before travel.
- Judge success by useful conversations and next steps, not badge scans alone.
- Capture private conversations carefully and do not publish them without permission.
