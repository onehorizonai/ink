# Hackathon Program Plan Format

## Use When

- Planning a hackathon, build night, developer challenge, internal innovation sprint, API challenge, or demo day.

## Required Output

1. Theme, builder audience, and build constraint.
2. Eligibility, team, IP, code of conduct, and prize rules.
3. Venue/platform, WiFi, power, food, beverages, safety, and staffing.
4. Workshop, mentor, and technical support plan.
5. Submission and demo process.
6. Judging rubric and judge briefing.
7. Sponsor/API requirements.
8. Showcase, recruiting/product, and community follow-up.

## Rules

- Make the build constraint clear enough to judge.
- Prepare starter materials and support before promotion.
- Do not bury rules until demo time.
