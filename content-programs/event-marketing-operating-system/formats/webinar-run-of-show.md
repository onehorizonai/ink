# Webinar Run Of Show Format

## Use When

- Creating a webinar, livestream, virtual demo, online workshop, fireside chat, office hours, or replay-first event.

## Required Output

1. Live and replay promise.
2. Speaker roles and moderation owner.
3. Platform and technical checklist.
4. Run of show with timings.
5. Poll, chat, Q&A, handout, and CTA plan.
6. Demo fallback and recording plan.
7. Reminder and follow-up sequence.
8. Replay chapters and repurposing ideas.

## Rules

- Put value before housekeeping.
- Prepare live and replay openings separately.
- Segment follow-up for no-shows, attendees, question askers, CTA clickers, and replay viewers.
