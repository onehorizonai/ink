# Engagement Comment Format

## Use When

- The run needs a first comment or follow-up question after posting.

## Structure

1. Ask one concrete question tied to the card.
2. Keep it easy to answer from lived experience.
3. Avoid a product pitch.

## Examples Of Question Jobs

- Ask for the weirdest version of the same problem.
- Ask which bullet felt too real.
- Ask what the audience would add as a fourth bullet.
