# Run Brief Prompt

Use this prompt shape when creating one or more Daily Recap Card runs.

```text
Create <count> Daily Recap Card runs for <audience> about <theme>.

For each run, return:
- run_id
- planned_date
- card title
- three short card bullets
- caption for <channel>
- first comment
- asset brief for the card image

Constraints:
- keep the visual copy short enough for a fixed card template
- keep the tone specific, funny, and audience-native
- do not include private claims unless provided in the brief
- do not publish or schedule anything
```
