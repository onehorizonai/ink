# Workflow

## Inputs

- Audience pain, team ritual, product category, or weekly theme.
- Brand or visual constraints from the selected profile or private local pack.
- Target channel and planned date.

## Steps

1. Pick one audience pain or recurring workplace moment.
2. Generate 5 to 10 candidate recap concepts.
3. Select the strongest concepts by specificity, freshness, and audience fit.
4. Write three short card bullets for each run.
5. Write a caption that creates context and includes restrained keywords or hashtags when the channel supports them.
6. Write one first comment or reply prompt.
7. Create the image manually or with the profile's chosen design tooling.
8. Add the run to `calendar.csv`.
9. After publishing, update `performance.csv`.

## Guardrails

- Do not invent private company claims or customer facts.
- Do not make the card copy longer than the visual template can carry.
- Do not rely on brand-specific assets in tracked starter packs.
- Avoid references that require licensed media unless the user confirms rights.

## Output Bundle

Each run should leave behind:

- card bullets
- caption
- first comment
- asset brief or rendered asset path
- planned or published URL
- performance notes when available
