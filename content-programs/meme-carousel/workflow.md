# Workflow

## Inputs

- Audience pain or theme.
- Target channel.
- Allowed visual sources or asset constraints.
- Desired slide count.

## Steps

1. Pick one theme for the whole carousel.
2. Generate more meme angles than needed.
3. Select the best 3 to 8 slides.
4. For each slide, write the visual reference, overlay copy, and reason it belongs.
5. Write the caption and optional first comment.
6. Create the carousel assets manually or with an approved image workflow.
7. Add the planned run to `calendar.csv`.
8. Add published URL and performance metrics after posting.

## Guardrails

- Do not assume rights to movie, TV, or internet meme stills.
- Do not make unsupported competitor or customer claims.
- Do not make the final slide a forced product pitch unless the program brief explicitly allows it.
- Do not repeat a previous carousel's exact opening move without a new angle.

## Output Bundle

Each run should include:

- carousel concept
- slide-by-slide copy and asset notes
- caption
- first comment when needed
- publish and performance fields
