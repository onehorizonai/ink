# Run Brief Prompt

Use this prompt shape when creating one or more Meme Carousel runs.

```text
Create <count> Meme Carousel run(s) for <audience> about <theme>.

For each run, return:
- run_id
- planned_date
- carousel concept
- <slide_count> slide briefs with visual direction and overlay copy
- caption for <channel>
- optional first comment
- asset rights or sourcing notes

Constraints:
- keep each slide to one idea
- make the carousel feel cohesive
- do not assume rights to copyrighted meme images
- do not publish or schedule anything
```
