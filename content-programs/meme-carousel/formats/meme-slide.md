# Meme Slide Format

## Use When

- Writing copy or asset notes for one carousel slide.

## Structure

1. Visual reference or asset direction.
2. Overlay text.
3. Optional small context note.

## Copy Rules

- Keep the overlay text short.
- Make one joke or point per slide.
- Use consistent capitalization and spacing across the carousel.

## Avoid

- Long punchlines.
- Multiple ideas on one slide.
- Visual references the user does not have rights to publish.
