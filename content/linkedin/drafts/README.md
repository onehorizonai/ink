# Draft Workspace

Store unpublished writing here.

## Rules

- Keep drafts separate from the published corpus.
- Use one file per draft.
- Save by format folder.
- Treat everything here as not yet posted.
- Keep actual draft files local. Only workspace docs and keep files should stay tracked.

## Saving

Use `.agents/linkedin-social-writer/scripts/create_draft.py` or write a Markdown file directly with the draft template at `.agents/linkedin-social-writer/templates/storage/draft.md`.
