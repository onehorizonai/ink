# Draft Workspace

Store unpublished blog-article drafts here.

## Rules

- Keep drafts separate from the published corpus.
- Use one file per draft.
- Treat everything here as not yet published.
- Keep actual draft files local. Only workspace docs and keep files should stay tracked.

## Saving

Use `.agents/blog-post-writer/assets/templates/blog-article.mdx` as the starting point.

Do not save placeholder asset manifests, JSX comments, or editorial TODO blocks inside draft files.
