## Headline Rules

- Lead with the clearest version of the promise.
- Prefer specificity over cleverness.
- Make the value legible even without the rest of the page.
- If a headline sounds impressive but could fit any company, it is too vague.

## Headline Patterns

Use these as starting points, not rigid formulas:

- achieve outcome without pain
- product or capability for audience
- product or capability for audience to achieve outcome
- achieve outcome by mechanism
- never suffer pain again
- turn input into outcome
- stop pain, start outcome
- the category that differentiator
- achieve outcome in timeframe

## Subheadline Rules

- Expand the headline instead of repeating it.
- Add specificity, scope, audience fit, or proof.
- Keep it to one or two sentences.

## CTA Rules

Prefer the action and the outcome over generic button text.

Weak CTA patterns:

- submit
- sign up
- click here
- learn more

Stronger CTA patterns:

- start free trial
- book my demo
- get the guide
- see pricing
- see it in action
- create your first [thing]

Useful CTA structure:

- action verb
- what they get
- qualifier when needed

## Style Moves

Use these only when they improve clarity or momentum:

- be direct instead of circling the point
- use a rhetorical question when it sharpens recognition
- use an analogy when the concept is abstract and the analogy makes it concrete
- use humor only when it fits the brand and does not weaken clarity

## Voice and Tone

Set the tone before drafting:

- casual and conversational
- professional but friendly
- formal and enterprise-oriented

Adjust intensity by element:

- headlines can push harder
- body copy should stay clear
- CTAs should stay action-oriented
