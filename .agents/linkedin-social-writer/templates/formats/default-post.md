# Default post

## Use when

- the post is a general insight, lesson, or observation
- there is no stronger custom format yet

## Structure

1. Hook
2. Core point
3. Proof, example, or explanation
4. Close

## Notes

- keep one central point
- avoid generic engagement bait
- keep the CTA aligned with the usual voice
