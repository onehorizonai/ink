# Style Capture

## Use a Small, Relevant Set

Build the voice profile from 3-5 examples that match:

- the same format
- a similar audience
- a similar goal
- a similar asset pattern if visuals matter

Do not overfit to one unusually high-performing post unless the user explicitly wants that style.

## Capture These Markers

- opening pattern
- first visible line pattern on longer posts
- sentence rhythm
- recurring sentence shapes or phrases that should not be repeated blindly
- paragraph length and spacing
- level of specificity
- point of view and confidence
- amount of personal detail
- CTA style
- emoji and punctuation habits
- hashtag habits
- how the copy references the image, carousel, link, or prior conversation

## Write a Short Voice Profile

Before drafting, summarize the voice in 5 lines or fewer:

- Usually opens by:
- Usually sounds:
- Usually avoids:
- Usually closes by:
- Repetition risks:

## Watch for Format Drift

Do not assume the post voice is identical to the DM voice.

- `posts` may be broader and more public.
- `comment-replies` should feel conversational and thread-aware.
- `dms` should be more specific, lower-pressure, and more personal.
- `reposts` should add interpretation, not filler praise.

## Avoid These Failure Modes

- copying sentence fragments from a single exemplar
- repeating the same hook, close, transition, or sentence shape across multiple posts
- defaulting to generic platform cliches
- adding intensity that the archive does not support
- using emoji, hashtags, or line breaks more aggressively than the archive does unless the brief explicitly asks for them
