# Copy Rules

Use these rules to lock exact copy atoms inside a page brief.

## Decision Order

Work in this order:

1. page purpose
2. audience problem
3. offer and value
4. proof
5. CTA

## Confirm Before Locking Copy

- page type
- audience
- primary problem
- offer or capability
- primary CTA
- secondary CTA, if any
- traffic source or awareness stage when known

## Core Principles

- Clarity over cleverness
- Benefits over features
- Specificity over vagueness
- Customer language over internal language
- Honest proof over hype
- One idea per section

## Hero and Above-the-Fold Rules

- The first screen answers:
  - what is this
  - why it matters
  - what action comes next
- Keep the H1 simple and specific.
- Keep the hero subheading concise.
- Keep one prominent primary CTA above the fold.
- Use a secondary CTA only when it serves a different readiness level.
- Add one to three trust cues when they reduce first-click hesitation.

## H1 Patterns

Use these as starting patterns, not rigid formulas:

- achieve outcome without pain
- product or capability for audience
- achieve outcome by mechanism
- stop pain, start outcome
- turn input into outcome

## Section-Level Guidance

### Problem Section

- Show the audience you understand the situation.
- Name concrete frustrations, not abstract inefficiency.

### Solution or Benefits Section

- Translate capabilities into outcomes.
- Limit the number of major benefits so the page keeps focus.

### Proof Section

- Use proof that matches the claim:
  - customer proof
  - metrics
  - screenshots
  - process clarity
  - implementation reassurance

### Objection Handling

- Address likely hesitation directly.
- Use FAQ, comparison logic, guarantees, or setup clarity when they fit.

### Final CTA Section

- Re-state the value clearly.
- Repeat the primary action without inventing urgency.

## CTA Rules

- Keep CTA wording action-oriented.
- Prefer what the user gets over what the user submits.
- Match CTA intensity to funnel stage.
- Avoid competing primary actions on the same page.

### CTA Intensity by Funnel Stage

- early-stage pages: lower-pressure CTA such as learn more, see how it works, or view the guide
- mid-stage pages: evaluation CTA such as book a demo, compare options, or see pricing
- late-stage pages: action CTA such as start trial, contact sales, or connect integration

## Tone and Language Guardrails

- Use plain language unless the audience genuinely expects technical terms.
- Avoid vague buzzwords like `innovative`, `seamless`, or `revolutionary` unless backed by something concrete.
- Avoid hedging and filler.
- Avoid fabricated proof or empty superlatives.

## Things to Avoid

- headline cleverness that hides the offer
- weak or generic benefit language
- too many claims in one section
- unsupported metrics
- using the same CTA logic for every page type
